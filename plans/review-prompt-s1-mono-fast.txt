The rewrite:
- menu/menu_text.c mt_bits: the edges set by column (ink_cols, only when inked), then the cells the band reaches, each glyph row's six bits (bits 7..2) shifted into place with two byte ORs; a cell cut on the band's left is shifted left by the cut (lshift), and bits at or past w are masked off (rmask). Spaces past the string are skipped.
- graphics/lcd_bus.c lcd_blit_mono: the scratch is now a union of 512 bytes and 256 halfwords (lcd_scratch is its byte view, so sizeof and every other user is unchanged); the expansion stores one halfword a pixel from lut[2] (each colour byte-swapped so its little-endian bytes are panel order), eight to a source byte, and flushes before a row that wouldn't fit, so rows never split (a row is at most FRAME_W = 128 px).
- scripts/menu_s0_test.c: an exhaustive comparison of mt_bits against a per-pixel reference (every band start and width up to 128 over lines with lead and trail 0-2, both inks, 0-20 cells, short strings, the extras and a code the face hasn't, bits past w required clear); two planted mutations (the right mask, the left shift) each fail it.
