ak820-agent -- the host agent for an AJAZZ AK820 Pro running the QMK firmware
from this repository's Releases (https://github.com/jdlien/ak820-pro/releases)

What it does: keeps the keyboard's LCD clock in sync with this PC to within a
few milliseconds, and shows the track you are playing, read from Windows' own
media API (SMTC) -- Spotify, Apple Music, foobar2000, any browser.

Needs: Windows 10 or 11, and the firmware from the SAME release on the
keyboard. Nothing else -- no Python, no runtime, no driver, no admin rights.

1. Unzip anywhere.
2. Open a terminal (PowerShell or cmd, NOT elevated) in that folder and run:

       .\ak820 install --clock --radio --lockchan

   That copies ak820.exe and ak820-agent.exe to %LOCALAPPDATA%\ak820pro\bin,
   registers a per-user Scheduled Task (\ak820pro\AK820Pro-agent) that starts
   at logon, and starts it now. You can delete the zip afterwards.

   Over the USB cable the track always shows. Each flag adds a job; leave
   off any you don't want:

       --clock      keep the keyboard's clock in sync with this PC
       --radio      show the track over the 2.4G dongle, with the cable out
       --lockchan   show the track over Bluetooth, signalled through the
                    keyboard's lock lights (never Caps Lock)

   To change them later, run install again with the flags you want.

3. Useful afterwards. The installed copy is not on PATH; from PowerShell it
   is:  & "$env:LOCALAPPDATA\ak820pro\bin\ak820.exe" status

       ak820 status         is it running, the last sync and push, the board's own health counters
       ak820 uninstall      stop and remove the task (binaries and logs stay)
       ak820 probe          what Windows' media API sees, if the LCD shows nothing
       ak820 health         the firmware's stall counters, if typing feels off
       ak820 --version      which build, and which firmware protocol it speaks

Logs and status:  %LOCALAPPDATA%\ak820pro\ak820-agent.log
                  %LOCALAPPDATA%\ak820pro\ak820-agent.status

If Windows SmartScreen objects when you double-click an .exe from the zip:
run it from a terminal instead, which is what the steps above do.

Everything in ak820.exe reads the keyboard; nothing in it writes the
keyboard's flash. The clock is written only by the daemon, and only when it
was installed with --clock. Provisioning the LCD assets stays in ak820ctl,
built from the repository.
